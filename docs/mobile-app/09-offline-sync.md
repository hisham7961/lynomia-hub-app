# 09 · دون اتصال والمزامنة (§31)

`hub_sync_class` الخادمية تقود كل شيء — التطبيق لا يقرر ما يُخبأ:

| الصنف | السلوك |
|---|---|
| `CACHEABLE_INCREMENTAL` | مزامنة تزايدية بمؤشر `(updated_at, id)` + شواهد حذف + `version` للكتابة |
| `CACHEABLE_READ_ONLY` | خبيئة قراءة بلا كتابة |
| `ONLINE_ONLY` | لا سجل يُخبأ (الافتراض) |
| `SENSITIVE_NO_PERSIST` | **لا يهبط القرص أبداً** — ولا يبث الخادم سجلاً أصلاً |
| `NOT_APPLICABLE` | من `context`/`bootstrap` |

- الخبيئة AES-256-GCM (`EncryptedJsonCache`) بمفتاح في المخزن الآمن؛ مفاتيحها
  معزولة بالمستخدم والسياق (`sync_u_{uid}_…`) — الخروج يطهرها.
- حقل `sec` لا يُخبأ قط (يجرد خادمياً أصلاً).
- **بوابة العميل ONLINE_ONLY عملياً:** قارئات `portal/*` لا تمر بمحرك
  المزامنة ولا تهبط القرص — عالم العميل يقرأ حياً.
- تعارض النسخ: `If-Match` ⇒ `VERSION_CONFLICT` يعرض للمستخدم — لا كتابة
  صامتة فوق أحدث.

التفصيل في `docs/offline-sync.md`.
