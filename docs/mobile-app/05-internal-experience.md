# 05 · تجربة المستخدم الداخلي

خمس وجهات سفلية + وصول سريع (إشعارات/رسائل/ماسح):

| الوجهة | المصدر | ملاحظات |
|---|---|---|
| الرئيسية | `GET home` | انتباه/مواعيد/مهامي/مشاريعي/آخر النشاط + `mode: internal` |
| مهامي | `GET home` (my_work) + الوحدات | قوائم العمل الشخصية |
| المجالات | `bootstrap.ia` | شجرة المجالات المنطَّقة — محرك الوحدات العام |
| البحث | `GET search` | عالمي منطَّق |
| حسابي | bootstrap + جلسات | سياق العرض، الأمان، الخروج |

- **محرك الوحدات العام (§21):** `GET schema` يقود القوائم والسجلات والنماذج
  (13 نوع حقل) و`GET {module}/{id}/actions` يقود الإجراءات — لا شاشة مخصصة
  لكل وحدة.
- **الاعتمادات بلا طريق ويب مسدود (§20):** قائمة/عرض/اعتماد/رفض داخل التطبيق،
  والكتابة المحمية تصف طلب اعتماد حقيقياً.
- **إدارة أعضاء العميل (§15):** من سجل وحدة `clients` زر «أعضاء العميل» لمن
  يملك `clients:e` — انظر `06-client-experience.md`.
- من سجل العميل/المشروع: التعليقات والمرفقات على مفتاح `(module, record_id)`
  الواحد، وخيار `internal` للتعليق الداخلي (لا يبث للعملاء أبداً — خادمياً).
