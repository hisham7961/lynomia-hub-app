# 08 · غرفتا المشروع (§17)

لكل مشروع غرفتان منفصلتان بجمهورين — العزل خادمي بنيوي:

| | الغرفة الداخلية | غرفة العميل |
|---|---|---|
| الجمهور | الفريق الداخلي حصراً | العميل + الفريق |
| المصدر | تعليقات السجل (`GET comments?module&record`) وقنوات `audience=internal` | `GET portal/conversations/{id}` |
| الشرط للعميل | **لا تصل أبداً** (404 حتى لو أُدرج عضواً خطأً — الجمهور شرط فوق العضوية) | عضوية **و**جمهور عميلي معاً |
| `internal` | التعليق الداخلي يظهر | محجوب بنيوياً في القارئ — لا يبث أبداً |

- الكتابة للعميل عبر سكة التعليقات الواحدة (`POST comments` بقناة الغرفة) —
  الخادم يفرض `internal=false` لحساب العميل مهما أرسل التطبيق.
- الفريق الداخلي يرى غرفة العميل ويشارك فيها؛ والعميل لا يعلم بوجود الغرفة
  الداخلية أصلاً.
- في التطبيق: غرفة العميل شاشة محادثة في قشرة البوابة؛ الغرفة الداخلية
  تبويب التعليقات على سجل المشروع في القشرة الداخلية.
