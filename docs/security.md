# الأمان (§140 مراجعة قبل الإتمام)

## المراجعة البند ببند

| البند | الحال | الإثبات |
|---|---|---|
| تخزين الاعتماد | Keychain/Keystore حصراً عبر `SecureStore`؛ لا SharedPreferences/SQLite/JSON صريح | `core/auth/token_store.dart` + مراجعة الشيفرة |
| سباق التحديث | Future واحد مشترك؛ تزامن 401 ⇒ تدوير واحد | اختبار `api_client_test` «تحديث واحد لا خمسة» |
| تدوير الرمز | استبدال ذري؛ `REFRESH_TOKEN_INVALID` يمسح ويعيد للدخول | اختبار الاستمرار بعد التدوير |
| تسجيل الرموز | `RedactingLogger` يطمس `lyma_/lymr_/Bearer` والمفاتيح الحساسة حتى في التطوير | `redacting_logger_test` |
| تشفير الخبيئة | AES-256-GCM بمفتاح في المخزن الآمن؛ البايتات ليست نصاً | `encrypted_cache_test` |
| sensitive no-persist | رفض بنيوي + محو بقايا + لا بث خادمي أصلاً | `sync_engine_test` + `encrypted_cache_test` |
| تسرب السياق | مفاتيح الخبيئة تتضمن (مستخدم/شركة/عميل)؛ التبديل يعيد الجلب؛ الترويسات تضيق ولا توسع خادمياً | `sync_engine_test` عزل السياق |
| تخويل الرابط العميق | الشاشة تجلب من الخادم — سجل خارج النطاق 404/403 صادقة؛ لا خبيئة تعرض كسلطة | بنية `RecordScreen` |
| وصول المرفقات | مسارات نسبية مصادقة فقط؛ لا روابط عامة ولا base64 | `file_repository` + عقد §07 |
| خصوصية الدفع | مزود صفري صادق؛ الحمولة إشارة؛ لا نص حساس محلياً | `push_registrar` |
| تسرب رابط/رمز | لا رمز في URL (مثبت اختباراً)؛ `X-Request-Id` فقط للترابط | `api_client_test` |
| تشخيص المطور | kDebugMode فقط؛ لا رموز/أسرار في الشاشة | `diagnostics_screen` |
| HTTPS الإنتاج | بوابة `AppEnv.validate` ترفض HTTP/غياب المضيف؛ لا تعطيل TLS في الشيفرة | `app_env_test` |
| سلوك النسخ الاحتياطي | أدناه | — |

## النسخ الاحتياطي (§141)

- **iOS:** عناصر Keychain بـ`first_unlock_this_device` — لا ترحيل iCloud/نسخ.
- **Android:** flutter_secure_storage فوق Keystore — المفتاح العتادي لا يُنسخ،
  فالقيم المنسوخة غير قابلة للفك على جهاز آخر. الخبيئة المشفرة عديمة القيمة
  بلا مفتاح المخزن الآمن. قبل النشر يوصى بضبط
  `android:allowBackup=false` أو قواعد `dataExtractionRules` تستثني دليل
  الدعم — مقيد في release-checklist.md (قرار متجر لا بنية).

## الحافظة واللقطات (§142)

القيم السرية (`sec`) تعرض مقنعة ولا تنسخ تلقائياً؛ لا قيود لقطات عامة بلا
سياسة خادمية (لا اختراع قيود).
