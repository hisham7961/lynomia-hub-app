# 14 · الاختبار (§52)

- **لا اختبار يلمس خدمة حقيقية:** `test/fakes/fakes.dart` — ناقل HTTP مبرمج
  يسجل كل طلب (ترويسات وأجسام)، مخزن آمن في الذاكرة، حاوية اختبار كاملة.
- التغطية (93 اختباراً):
  - `test/core/` — ApiClient (تجديد، Idempotency، الحجب)، الخبيئة المشفرة،
    محرك المزامنة، المسجل الحاجب، البيئات.
  - `test/features/` — تدفقات المصادقة، محرك الوحدات، الاتصال،
    **وتجربة العميل** (`client_experience_test.dart`): اختيار القشرة من
    `account_type`، عزل القشرتين بالملاحة المباشرة، عقد التفعيل (لا
    Authorization على السكة العامة، الانتهاء الصادق)، إدارة الأعضاء
    (Idempotency + غرض التصعيد المسمى من 428)، وقارئ البوابة.
  - `test/widget/` — RTL والشاشات الحرجة بالتطبيق الكامل.
  - `test/contract/` — لقطات `contracts/` تطابق العقد المستهلك؛ تحدث عمداً
    عبر `tool/update_contracts.sh`.
  - `test/governance_test.dart` — تطابق النسخة في المواضع الأربعة.
- القطع قبل الدفع: `dart format --set-exit-if-changed .` ثم `flutter analyze`
  ثم `flutter test` — والحزمة الخلفية على المحركين إن تغيرت الخلفية (§53).
