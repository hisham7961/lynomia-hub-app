# تغطية أنواع الحقول (§20)

المصدر: أنواع `config/hub.php` كما يبثها `GET schema` (المحجوب يسقط خادمياً،
و`readonly` من قناع الدور). الجرد من الشجرة المرجعية عند SHA اللقطة:
**13 نوعاً** — كلها مغطاة، و**الأنواع المطلوبة المجهولة = 0**.

| النوع | العدد في السجل | العارض (قراءة) | المحرر (نموذج) |
|---|---|---|---|
| `text` | 309 | نص | حقل نصي |
| `ref` | 305 | اسم/معرف (مفرد أو قائمة) | منتقي مرجع خادمي (بحث في وحدة `ref` عبر المحرك العام؛ multi رقائق) |
| `sel` | 254 | نص القيمة | قائمة منسدلة؛ multi رقائق اختيار من `options` |
| `ta` | 160 | نص متعدد أسطر | حقل متعدد أسطر |
| `num` | 129 | `Decimal` بدقة الخادم، LTR — لا double (§81) | حقل رقمي (يرسل النص كما أدخل) |
| `date` | 114 | تنسيق محلي | منتقي تاريخ ⇒ `YYYY-MM-DD` |
| `url` | 55 | رابط قابل للفتح، LTR | حقل URL |
| `tags` | 35 | رقائق | إدخال رقائق (إضافة/حذف) |
| `file` | 33 | حضور + اسم — التنزيل عبر بوابة الملفات | يدار من تبويب المرفقات (رفع مقطع/إرفاق) — ملاحظة صريحة في النموذج، لا إسقاط صامت |

- **`readonly`** (قناع `ro` الخادمي): يعرض معطلاً بأيقونة قفل في العارض
  والمحرر — لا يبث في جسم الكتابة.
- **نوع مستقبلي مجهول (§93):** يسقط لعارض/محرر نصي آمن — لا انهيار إصدار؛
  واختبار المحرك يوكد المجموعة المعروفة فيكشف CI أي نوع جديد يبثه المخطط
  (فشل اختبار صريح = تنبيه تنفيذ لا إسقاط صامت).

  يحمل الأنواع الـ13 كلها، و`FieldValueView`/`FieldEditor` يغطيانها فرعاً فرعاً.
